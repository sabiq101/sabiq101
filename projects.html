VLSI / In-memory computing 2025

In-Memory Compute Macro Using MRAM Crossbar Array

Mixed-signal MRAM macro for read/write, compute, and associative search

  • Developed an open-source Cadence/Virtuoso-based MRAM compute macro targeting memory-wall bottlenecks.
  • Implemented and validated analog blocks including MTJ crossbar read/write paths, TIA, and flash ADC in Spectre.
  • Built a synthesizable digital subsystem with CAM engine, priority encoder, and FSM controller.
  • Verified digital flow through VCS simulation, Design Vision synthesis, and Innovus place-and-route with timing and area closure.
  • Defined modular analog-digital interfaces to support future end-to-end mixed-signal co-simulation and integration.

Distributed AI 2025

JARVIS

Joint Architecture for Remote, Versatile Inference Services

  • Built a decentralized LLM inference system on a peer-to-peer cluster of Raspberry Pi devices for fully offline operation.
  • Partitioned transformer layers across nodes and passed activations through a deterministic execution pipeline.
  • Implemented orchestration with heartbeat monitoring and dynamic rerouting so inference continues during node failures.
  • Added encrypted inter-node communication channels and on-device processing for privacy-preserving deployment.
  • Integrated monitoring tools for node status, latency, and failover events to validate resilient edge-AI performance.
  • Distributed systems
  • LLM inference
  • Raspberry Pi
  • Networking
